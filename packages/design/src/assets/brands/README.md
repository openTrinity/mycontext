# 品牌资产（第三方）

这里放**第三方产品的官方标识 SVG**，作为组件的来源真相（source of truth）。
同名 `.tsx` 组件由 `pnpm sync:brand-icons` 从这些 SVG 生成，不要手改生成物。

做法参考的是参考实现的图标资产约定：SVG 原文件留在 `assets/` 下，
组件是生成产物；生成时**不把颜色替换成 `currentColor`**——品牌色是识别的一部分，
换主题也不该让钉钉从蓝变绿。（对我们自己的界面图标才做 currentColor 化。）

## 约束

- 只放**官方**标识，不自己描摹：描摹出来的东西既不准确，也是商标风险。
- 文件名用渠道 id（`dingtalk.svg` 对应 `channelId: "dingtalk"`），
  这样组件与渠道注册表能一一对上。
- 不改 SVG 内容（除了必要的格式化）。要调尺寸/圆角在组件层做，
  否则下次更新官方资产时改动会丢。
